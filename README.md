# 🐸 Anuroth

> A custom website created for the Anuroth Minecraft server.

Anuroth is a collaborative project that brings together Minecraft, visual design, creativity, and web development.

This website was created to transform the server's visual identity into an interactive web experience, connecting players to the server, its community, and its universe.

🌐 **Live Website:** [www.anuroth.com.br](https://www.anuroth.com.br)

## 📖 About the Project

Anuroth is a Minecraft server created by Lincoln Kawai Dalla Costa Santos.

I participate in the project by helping with technical troubleshooting, testing, and giving feedback during the development of the server, including suggestions for elements such as the lobby.

The website became my main technical contribution to Anuroth. My goal was to take the visual identity and artwork created for the server and turn them into a functional and interactive website while preserving the original creative direction.

The project is still evolving alongside the server, so the website is designed to grow and change as new ideas, content, and features are created.

## ⚙️ How It Works

The website is divided into three full-screen sections, each representing a different part of the Anuroth experience.

- **First section:** introduces Anuroth and includes a button that copies the Minecraft server IP directly to the user's clipboard.
- **Second section:** contains interactive visual elements that connect to external content and is planned to evolve into a visual gallery.
- **Third section:** includes characters with interactive dialogue bubbles.

JavaScript is used to handle interactions such as copying the server IP, character dialogue, and navigation between sections.

The layout also adapts to different screen sizes, with specific adjustments for mobile devices.

## 📚 What I Learned

This project taught me a lot about turning a visual concept into a functional website.

One of my biggest challenges was responsive design. Before this project, I had not worked with adapting a complex desktop layout for different screen sizes. I learned that responsive design is not simply about making everything smaller, but about reconsidering positioning, interactions, and the overall experience for each type of device.

I also improved my understanding of JavaScript events, DOM manipulation, CSS positioning, and debugging.

Most importantly, I became more comfortable with experimenting. Many parts of the website required testing different solutions, observing the results, finding problems, and making small adjustments until the behavior felt right.
